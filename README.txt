=== LIVE CHAOS PLUGIN ===

Comandi puliti inclusi (nessun riferimento a follow/sub):
- /casa [testo opzionale] -> Costruisce una casa 5x5x4 blocco per blocco con colori casuali. Se aggiungi un testo dopo /casa (es. /casa Marco), mette anche il cartello sopra la porta!
- /pioggiatnt -> Scatena una pioggia di TNT sopra il giocatore.
- /caos -> Attiva uno dei 5 eventi pazzi casuali (Polli Kamikaze, Gabbia con Creeper Carichi, Pioggia di Incudini, Razzo Spaziale, Slime Giganti).

Come compilare in .jar:
1. Estrai questo zip.
2. Apri il terminale nella cartella LiveChaosPlugin.
3. Esegui: mvn clean package
4. Troverai il file compilato in: target/LiveChaosPlugin-1.0.jar
